This project is an AI-Based Recommendation System developed using Java. The application suggests movies to users based on their interests and previous ratings. The system uses a simple collaborative filtering approach, which is one of the most widely used recommendation techniques in artificial intelligence and machine learning applications.

The program stores user ratings for different movies and analyzes similarities between users to generate recommendations. If two users have similar interests in certain movies, the system recommends other highly rated movies liked by one user to the other. This creates a personalized recommendation experience similar to modern streaming and e-commerce platforms.

The project demonstrates important AI and programming concepts such as user preference analysis, recommendation algorithms, data structures, and collaborative filtering. Java Collections like HashMap and Set are used to efficiently manage and process the recommendation data. The system is console-based, simple to understand, and easy to enhance with advanced AI libraries, databases, graphical interfaces, or real-world datasets.

This project is useful for understanding the fundamentals of recommendation engines used in platforms like Netflix, Amazon, YouTube, and Spotify.
